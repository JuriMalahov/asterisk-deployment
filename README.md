Автоматизированное решение для развёртывания и настройки call-центра на базе Asterisk и Ubuntu 22 с использованием Ansible.
Решение устанавливает Asterisk, настраивает 3 IP-телефона, очередь и ожидание.

Требования:
+ Linux Ubuntu 22
+ 4 ГБ ОЗУ
+ 2 ЦПУ
+ 40 ГБ дискового пространства
+ Python
+ Ansible

Перенесите на узел файлы из репозитория. В файле inventory.ini поменяйте значение параметра ansible_become_pass на свой пароль от root. В файлах extensions.conf и pjsip.conf указаны настройки для 3-х IP-телефонов. При необходимости можно добавить свои.

Выполните установку с помощью команды:
```
ansible-playbook playbook.yml
```
После этого система полностью готова к работе.
